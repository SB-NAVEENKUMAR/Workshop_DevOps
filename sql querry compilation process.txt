MASTER AND SLAVE SERVER WORKING PROCESS:


master machine -> bin loger -> slave machine
              
the master machine will update by use appkication.

the binloger to note the all update.

the the slave machine will use the binloger to update the slave machine.          


the system follow the ACID PROPERTIES

ATOMISITY
	
	not have duplicate and non real data and null data are not present.

CONSISTANCY
	
	continuesly update the master to slave machines data.
	
ISOLATION
	
	both machine are isolated.
	if master updae the slave will update, but if we update the slave not update the master machine.

DURABILITY
	
	if master machine are failed then we recover the machine by use of the slave machine to switch their ip and make to recover the machine and its data.
